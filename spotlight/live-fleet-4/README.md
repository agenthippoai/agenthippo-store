# Live Fleet 4

Workspace Spotlight view for **multi-agent workflow pipelines**. Shows running and finished orchestrations with per-step timelines, summaries, and artifact links.

Live Fleet 4 reads **fleet workflow JSON only** (not agent session logs). Status files are written by **`scripts/fleet-workflow.sh`** in this view during pipeline runs.

## Quick start

From the workspace root:

```bash
LF4=".agent-hippo/analytics/views/live-fleet-4"
FW="$LF4/scripts/fleet-workflow.sh"

# Refresh export + regenerate chart shell (CLI summary on stdout)
AGENTIDE_WORKSPACE_ROOT="$(pwd)" \
  node "$LF4/scripts/live-fleet-4-collector.cjs"

# Optional: background watcher (~2.5s) while a pipeline runs
node "$LF4/scripts/live-fleet-4-daemon.mjs" &
# kill via PID file: exports/live-fleet-4-daemon.pid
```

Open **Spotlight → Live Fleet 4** (panel `activeViewId: live-fleet-4` in `.agent-hippo/analytics/panel/views.yaml` or `views-team.yaml`).

## fleet-workflow.sh

Canonical path (only when this view is installed):

```bash
LF4=".agent-hippo/analytics/views/live-fleet-4"
FW="$LF4/scripts/fleet-workflow.sh"
```

| Command | When |
|---------|------|
| `init` | Start of run |
| `orchestrator --status …` | Update orchestrator block |
| `step --status in_progress` | **Before** `agenthippo ask` |
| `step --status done [--artifact ABS]` | **After** output verified |
| `finish` | All steps passed; archives to `history/` |

Example:

```bash
"$FW" init --workflow star-pipeline --title "GitHub Star Pipeline" \
  --subtitle "owner/repo" --orchestrator star-coordinator
"$FW" step --workflow star-pipeline --step 1 --agent joker1 \
  --label "Warm-up joke" --status in_progress
# … agenthippo ask joker1; copy the joke's first line into --summary …
"$FW" step --workflow star-pipeline --step 1 --agent joker1 \
  --label "Warm-up joke" --status done --summary "Why did the repo push to main? It couldn't branch out."
"$FW" finish --workflow star-pipeline
```

Writes to `.agent-hippo/fleet-workflows/` (active) and `.agent-hippo/fleet-workflows/history/` (finished). Use **absolute paths** for `--artifact`.

## List runs from the terminal

After collecting, inspect the export:

```bash
LF4=".agent-hippo/analytics/views/live-fleet-4"
AGENTIDE_WORKSPACE_ROOT="$(pwd)" node "$LF4/scripts/live-fleet-4-collector.cjs"

python3 - <<'PY'
import json
from pathlib import Path

p = Path(".agent-hippo/analytics/views/live-fleet-4/exports/live-fleet-4.json")
d = json.loads(p.read_text())
t = d.get("totals") or {}
print(f"running={t.get('running', 0)}  finished={t.get('finished', 0)}  history={t.get('history', 0)}")
print(f"export: {p}\n")

for lane, label in (("running", "RUNNING"), ("history", "HISTORY")):
    items = d.get(lane) or []
    if not items:
        continue
    print(f"=== {label} ===")
    for w in items:
        print(f"  {w.get('workflowId')}  run={w.get('runId')}  {w.get('subtitle') or w.get('title')}")
        print(f"    status={w.get('status')}  started={w.get('startedAt')}  finished={w.get('finishedAt')}")
        for s in w.get("steps") or []:
            art = (s.get("artifact") or "")[:70]
            print(f"    step {s.get('step')} {s.get('label')} [{s.get('status')}]  {art}")
    print()
PY
```

Raw workflow files (source of truth):

| Location | Meaning |
|----------|---------|
| `.agent-hippo/fleet-workflows/<workflowId>.json` | Active run (`in_progress`) |
| `.agent-hippo/fleet-workflows/history/<workflowId>-<runId>.json` | Archived finished runs |

## Layout

```
live-fleet-4/
├── README.md                 # this file
├── view.yaml                 # Spotlight view config (fleet-dashboard layout)
├── exports/
│   ├── live-fleet-4.json     # collector snapshot (host + iframe consume this)
│   └── live-fleet-4-daemon.log
├── charts/
│   └── live-fleet-4.html     # dashboard shell (regenerated by widget)
└── scripts/
    ├── fleet-workflow.sh            # workflow status writer → fleet-workflows/
    ├── live-fleet-4-collector.cjs   # fleet-workflows → export JSON
    ├── live-fleet-4-widget.cjs      # collector + HTML shell
    └── live-fleet-4-daemon.mjs      # watches workflow dir, auto-refresh
```

## Data flow

```
Orchestrator / runner (e.g. star-coordinator)
  └─ live-fleet-4/scripts/fleet-workflow.sh  →  .agent-hippo/fleet-workflows/
         │
         ▼
live-fleet-4-collector  →  exports/live-fleet-4.json
         │
         ▼
Spotlight Live Fleet 4  (Running + Finished lanes, step timeline)
```


## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Empty lanes | Run `"$FW" init`; confirm files under `.agent-hippo/fleet-workflows/` |
| Stale UI during a run | Restart `live-fleet-4-daemon.mjs`; keep Live Fleet 4 open in Spotlight |
| Collector shows 0 runs | Set `AGENTIDE_WORKSPACE_ROOT` to the repo root; check `~/.agent-hippo/paths.md` workspace |
| Broken artifact links | Pass **absolute** paths to `fleet-workflow.sh step --artifact` |
| `fleet-workflow.sh` not found | Install Live Fleet 4 view under `.agent-hippo/analytics/views/live-fleet-4/` |

Architecture notes: `PLAN/livefleet.md` at repo root.
