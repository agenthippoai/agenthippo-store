# Live Fleet 4

Workspace Spotlight view for **multi-agent workflow pipelines**. Shows running and finished orchestrations with per-step timelines, summaries, and artifact links.

Live Fleet 4 reads **fleet workflow JSON only** (not agent session logs). Artifacts are written by `.agent-hippo/scripts/fleet-workflow.sh` during pipeline runs.

## Quick start

From the workspace root:

```bash
# Refresh export + regenerate chart shell (CLI summary on stdout)
AGENTIDE_WORKSPACE_ROOT="$(pwd)" \
  node .agent-hippo/analytics/views/live-fleet-4/scripts/live-fleet-4-collector.cjs

# Optional: background watcher (~2.5s) while a pipeline runs
.agent-hippo/scripts/start-live-fleet-4.sh
# .agent-hippo/scripts/stop-live-fleet-4.sh
# .agent-hippo/scripts/start-live-fleet-4.sh --restart
```

Open **Spotlight → Live Fleet 4** (panel `activeViewId: live-fleet-4` in `.agent-hippo/analytics/panel/views.yaml` or `views-team.yaml`).

## List runs from the terminal

After collecting, inspect the export:

```bash
AGENTIDE_WORKSPACE_ROOT="$(pwd)" \
  node .agent-hippo/analytics/views/live-fleet-4/scripts/live-fleet-4-collector.cjs

python3 - <<'PY'
import json
from pathlib import Path

p = Path(".agent-hippo/analytics/views/live-fleet-4/exports/live-fleet-4.json")
d = json.loads(p.read_text())
t = d.get("totals") or {}
print(f"running={t.get('running', 0)}  finished={t.get('finished', 0)}  history={t.get('history', 0)}")
print(f"export: {p}\n")

for lane, label in (("running", "RUNNING"), ("history", "HISTORY")):
    items = d.get(lane) or []
    if not items:
        continue
    print(f"=== {label} ===")
    for w in items:
        print(f"  {w.get('workflowId')}  run={w.get('runId')}  {w.get('subtitle') or w.get('title')}")
        print(f"    status={w.get('status')}  started={w.get('startedAt')}  finished={w.get('finishedAt')}")
        for s in w.get("steps") or []:
            art = (s.get("artifact") or "")[:70]
            print(f"    step {s.get('step')} {s.get('label')} [{s.get('status')}]  {art}")
    print()
PY
```

Raw workflow files (source of truth):

| Location | Meaning |
|----------|---------|
| `.agent-hippo/fleet-workflows/<workflowId>.json` | Active run (`in_progress`) |
| `.agent-hippo/fleet-workflows/history/<workflowId>-<runId>.json` | Archived finished runs |

## Data flow

```
Orchestrator / runner (e.g. scripts/run-star-pipeline-live-fleet-4.sh)
  └─ fleet-workflow.sh  →  .agent-hippo/fleet-workflows/
         │
         ▼
live-fleet-4-collector  →  exports/live-fleet-4.json
         │
         ▼
Spotlight Live Fleet 4  (Running + Finished lanes, step timeline)
```

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Empty lanes | Run `fleet-workflow.sh init`; confirm files under `.agent-hippo/fleet-workflows/` |
| Stale UI during a run | `start-live-fleet-4.sh --restart`; keep Live Fleet 4 open in Spotlight |
| Collector shows 0 runs | Set `AGENTIDE_WORKSPACE_ROOT` to the repo root; check `~/.agent-hippo/paths.md` workspace |
| Broken artifact links | Pass **absolute** paths to `fleet-workflow.sh step --artifact` |

Architecture notes: `PLAN/livefleet.md` at repo root.
